# Agent Office v3 — 시안 비교

[비교 갤러리](index.html)에서 이미지를 고르고 각 HTML을 열어 애니메이션을 확인할 수 있습니다. `preview.png`는 별도로 캡처하는 정적 이미지이므로 HTML을 수정한 뒤에는 갱신해야 합니다. 각 시안은 자체 PNG 스프라이트와 표준 라이브러리만 사용하는 생성 스크립트를 포함합니다. 공급자 엠블럼은 실제 로고가 아닌 구별용 픽셀 기호입니다.

## A — Hearthside
- **컨셉:** 따뜻한 목재와 가구가 있는 탑다운 RPG 사무실. 그룹마다 관리자의 러그와 큰 책상이 있습니다.
- **장점 / 약점:** 친숙하고 상태가 눈에 잘 들어오지만 그룹이 커지면 방의 세로 길이가 늘어납니다.
- **스프라이트 시트 난이도:** 중간. 현재 상태 프레임을 묶고 캐릭터 방향·가구 변형을 추가해야 합니다.

## B — Little Workplace
- **컨셉:** 2:1 다이아몬드 바닥과 3/4 아이소메트릭 가구, 깊이 순서 배치를 쓰는 열린 사무실입니다.
- **장점 / 약점:** 입체감과 공간의 개성이 크지만 깊이 정렬과 책상 간격 관리가 어렵습니다.
- **스프라이트 시트 난이도:** 높음. 등각 방향별 프레임, 가려짐과 타일 기준점을 세심하게 맞춰야 합니다.

## C — Office Tower
- **컨셉:** 그룹마다 독립된 측면 단면 건물, 에이전트 층 위에 단독 관리자실이 있습니다.
- **장점 / 약점:** 그룹과 계층을 쉽게 구분하지만 에이전트가 늘면 건물이 높아집니다.
- **스프라이트 시트 난이도:** 중간. 측면 인물과 층 모듈은 단순하지만 높이 변화와 화면 이동이 필요합니다.

## D — Office 95
- **컨셉:** 청록색 데스크톱 위에 그룹별 Win95 창을 띄우고, 창 안은 약간 내려다보는 정면 사무실로 그립니다.
- **장점 / 약점:** 그룹 경계와 상태 집계가 명확하지만 창 장식이 공간을 차지합니다.
- **스프라이트 시트 난이도:** 중간. 별도 정면 스프라이트와 창 크기에 따른 레이아웃을 구현해야 합니다.
