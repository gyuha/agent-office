# Agent Office v5 — illustration studies

`flat/index.html`과 `chibi/index.html`은 각각 독립 실행되는 SVG 일러스트입니다. 외부 일러스트나 웹 폰트는 사용하지 않습니다. 모니터의 공급자 마크는 `assets/reference/provider-icons/`의 Paseo 제공 SVG 경로를 각 HTML에 포함한 것입니다. 상표는 해당 권리자에게 속하며 프로바이더 식별에 사용합니다.

## 리그와 장면 변환

두 시안 모두 `head`, `body`, `arm-upper left/right`, `arm-lower left/right`, `leg left/right` 그룹을 사용합니다. 각 그룹은 `transform-box: fill-box` 기준이며 머리와 몸통은 아래쪽 중앙, 위팔과 다리는 위쪽 중앙, 아래팔은 시작점 근처를 회전 중심으로 씁니다. 인물의 기준점은 몸통 중앙이고 개별 오피스의 좌석에 배치됩니다. 이름표는 `figure` 자식이라 이동할 때 같이 움직입니다. 잠든 상태는 기본 팔 그룹을 숨기고 접은 팔 path를 표시합니다. 관리자도 동일 리그이며 네 상태를 순환합니다.

아래는 **CSS 시안의 값**입니다. 실제 scene에서는 wall-clock 또는 누적 델타 시간으로 같은 곡선을 계산해야 합니다. CSS 애니메이션을 Chrome virtual time 캡처의 시간 기준으로 삼지 마세요.

Flat 이동 경로와 chibi 이동 경로는 시안 전용 경유점이며 충돌 탐색이 아닙니다. 실제 scene은 방의 가구와 다른 캐릭터를 고려해 경로를 계산해야 합니다. 두 HTML은 11개 책상과 모니터를 고정된 샘플 데이터로 보여 줍니다.

## Line / Paper Lines

`line/index.html`은 별도로 그린 가구와 1.5~2.5px 선, 해칭, 저강도 종이 노이즈를 사용합니다. `boil` 필터는 seed 2→3→4→3→2를 1.8초에 반복하며 displacement scale은 0.45입니다. 캐릭터 머리는 약 40px, 몸통과 다리는 약 68px 높이로 flat과 chibi 사이의 비율입니다. 실제 scene에서는 필터 성능과 사용자의 모션 감소 설정을 고려하세요.
