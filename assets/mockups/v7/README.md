## 동작과 축소
전원 provider 텍스트와 색을 함께 사용하며 관리자는 LEAD 프레임과 별도 위치로 구분합니다. Mina는 0~3초 working → 3~6초 sleeping → 6~8초 working, Theo는 phone → working → phone입니다. 전환은 0.45초 자세 크로스페이드이며 팔·몸의 움직임은 연속 사인 곡선을 사용합니다. 나머지 인원은 상시 working/sleeping/phone 예시입니다. 50% 화면에서 상태 라벨 11px, Zzz 20px가 남습니다.

검증: 각 HTML을 file://로 headless Chromium에서 열어 2.6초 후 1600×1000 preview.png를 캡처하며, 8.2초까지 오류·상태 이력을 확인합니다.

- 팔레트: 잉크 #303343, 세이지 벽 #c8d3bb, 귀리 바닥 #e2cba7, 민트 #6b9b94, 자두 #855b81, 블루 #668bb7, 살구 골드 #edba69.

- provider: claude 민트 / codex 블루 / gemini 자두와 텍스트 라벨. 관리자는 흰 머리·안경·골드 의상과 별도 상단 코디네이터 구역, orchestrator 라벨로 구분합니다.
- 동작: 타이핑 팔·몸 흔들림, 모니터 코드 갱신, +3/+10 상승과 페이드, Done!/PR 올림/테스트 통과 말풍선, 두 집중 작업자 주위 불꽃. sleeping은 고개 숙임·호흡·Zzz, phone은 화면 스크롤·손가락 동작입니다. Mina는 3초에 working→sleeping, 6초에 working 복귀, Theo는 반대로 phone→working→phone. 자세 전환은 0.45초 크로스페이드입니다.

- 50% 축소: 상태 라벨 10px, 숫자 14px, Zzz 19px가 남으며 색과 글자를 함께 사용합니다.
- 장점: 경영 시뮬레이션의 활기와 생활감, 성과와 상태가 동시에 읽힙니다.

- 실제 scene 이전 난이도: 중간~높음. 가구 깊이 정렬, 앉기 포즈, 이펙트 풀링과 HUD 데이터 연결이 필요합니다.
