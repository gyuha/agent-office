# Agent Office v4

`index.html`은 세 개의 분리된 방과 LPC 캐릭터를 2배 정수 확대하여 표시합니다. Alpha는 관리자와 6명, Beta는 관리자와 2명, Solo는 1명입니다. 자리 비움 캐릭터는 커피 구역까지 이동해 머문 뒤 돌아갑니다. `compose.py`는 제공된 ULPC 레이어에서 8명의 sit·walk·idle PNG를 만들고 `lpc-used-credits.csv`에 실제 사용 레이어의 저자 정보를 추출합니다. `draw_props.py`는 직접 그린 PNG를 생성합니다. 실행에는 Python 표준 라이브러리만 필요합니다.

앉은 캐릭터는 모니터 뒤쪽에서 관객을 향하는 **down 방향(정면)**을 사용하며, 모니터 뒷면 엠블럼을 앞쪽에 그립니다. walk는 이동 방향에 맞는 행을 사용합니다. 작업할 때 팔 잔상, 김·땀·종이를 올리고, phone은 화면과 빛, sleeping은 숙인 자세와 Zzz를 표시합니다. 고개 숙임은 합성된 프레임의 수직 이동과 오버레이로 표현하며 완전히 새로 그린 신체 프레임은 아닙니다. 자리 비움은 12초 주기로 경유점을 따라 이동하고 목적지에서 3.5초 머뭅니다. 검증 이미지는 `python3 render_check.py 3000`처럼 밀리초를 지정해 생성합니다. 검증 렌더러는 브라우저의 유리 반투명과 글꼴을 간략화합니다.

오피스 팩의 커피머신·복합기·정수기·TV·휴지통, 목재 가구 팩의 가구, 바닥 팩과 책장 팩을 사용했습니다. 직접 그린 자산은 모니터와 엠블럼, 바퀴 의자, 유리 파티션, 소파, 도시 창, 화분, 화이트보드, 유리 테이블과 상태 이펙트입니다. 모든 출처와 라이선스는 [전체 크레딧](../../CREDITS.md) 및 `lpc-used-credits.csv`에 있습니다.

현재 합성은 제공된 기본 남성 레이어와 헤어·의상 색 변형을 사용합니다. 제공된 관리자 재킷은 앉기 시트가 없어 관리자에게 별도 정장 레이어를 적용하지 못했고, 짙은 남색 옷과 유리 관리자실로 구분합니다. 관리자 상태는 시간에 따라 working·phone·sleeping·away로 순환합니다. 효과와 자세는 원본 LPC 프레임 위 편집으로 표현해 참고 화면의 완성도에는 미치지 못할 수 있습니다.
