# Agent Office 픽셀 시안

각 폴더의 HTML은 `sprites/`의 PNG를 로드하고 상태 프레임을 교체합니다. `preview.png`는 이전 HTML을 캡처한 이미지여서 현재 시안을 나타내지 않습니다. 새 캡처가 필요합니다. 원본 픽셀과 페이지 생성 코드는 `_tools/`에 있습니다.

## 01 Hearthside
- 따뜻한 색의 위에서 내려다보는 목재 방입니다. 16px 타일과 작은 캐릭터를 사용합니다.
- 친숙하고 그룹 구분이 쉽지만 작은 표정과 동작이 제한됩니다.
- 스프라이트 시트 이전 난이도: 낮음. 방향별 프레임을 추가해야 합니다.

## 02 Little Workplace
- 다이아몬드 바닥과 깊이 순서로 배치한 등각풍 사무실입니다.
- 공간감이 있지만 현재 책상과 캐릭터는 완전한 등각 투영으로 그려지지 않았습니다.
- 스프라이트 시트 이전 난이도: 높음. 등각 가구와 벽 접합을 다시 그려야 합니다.

## 03 Office Tower
- 그룹마다 독립된 건물이며 관리자가 꼭대기 층에 있습니다.
- 조직 계층이 뚜렷하지만 층별 수평 공간을 많이 차지합니다.
- 스프라이트 시트 이전 난이도: 중간. 층과 측면 가구가 필요합니다.

## 04 Pocket Office
- 제한된 올리브 팔레트의 휴대용 게임기풍 방입니다.
- 작은 크기로 읽기 쉽지만 HTML 배경 등은 엄격한 4색 제한을 충족하지 않습니다.
- 스프라이트 시트 이전 난이도: 낮음. 실루엣과 팔레트를 정리해야 합니다.

## 05 Neon Shift
- 어두운 배경과 분홍·청록 픽셀을 사용하는 야간 사무실입니다.
- 공급자와 활동이 두드러지지만 방의 기본 시점은 01과 유사합니다.
- 스프라이트 시트 이전 난이도: 중간. 야간 조명과 발광 표현이 필요합니다.

## 06 Chibi Work Club
- 커다란 얼굴과 파스텔 팔레트로 감정을 강조한 공간입니다.
- 얼굴이 친근하지만 기본 방의 시점은 01과 유사하고 과장 모션은 더 보강해야 합니다.
- 스프라이트 시트 이전 난이도: 중간. 표정과 동작 프레임을 늘려야 합니다.

## 07 Office 95
- 그룹마다 제목 표시줄, 메뉴와 상태 표시줄을 갖춘 별도 창을 사용합니다.
- 그룹 경계가 분명하지만 창 장식이 공간을 차지합니다.
- 스프라이트 시트 이전 난이도: 중간. 창 크기별 UI 타일이 필요합니다.

## 08 Agent / Office
- 차분한 저채도 팔레트와 작은 픽셀 캐릭터를 사용하는 IDE용 방입니다.
- 오래 띄우기에 무난하지만 기본 방의 시점은 01과 유사합니다.
- 스프라이트 시트 이전 난이도: 낮음. 축소 시 가독성을 검증해야 합니다.
