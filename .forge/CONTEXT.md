# Agent Office

Paseo 에이전트를 사무실의 직원처럼 보여 주는 플러그인. 에이전트의 상태를 오피스 장면으로 나타낸다.

## Language

**오피스(Office)**:
한 프로젝트 안에서 관리자 한 명과 그가 시작한 구성원들을 묶은 단위. 팀이 없는 에이전트는 혼자 쓰는 오피스를 가진다. 화면에서는 방 하나(카드 하나)로 그려진다.
_Avoid_: 방, 룸, 팀

**질문 대기(Awaiting human)**:
사람의 응답이 있어야 진행되는 상태. 도구 사용 승인 요청과 질문 답변 요청을 구분하지 않고 둘 다 포함한다.
_Avoid_: 승인 대기, 권한 대기(둘을 따로 부를 때만 사용)

**작업중(Working)**:
에이전트가 턴을 진행하고 있는 상태. 질문 대기 중인 에이전트는 멈춰 있으므로 작업중에 들어가지 않는다.
_Avoid_: 바쁨, 활성

**쉬는 중(Idle)**:
에이전트가 작업중도 질문 대기도 아닌 상태. 휴식(away), 휴대폰(phone), 잠(sleeping)을 모두 포함한다.
_Avoid_: 대기, 비활성

**노는 중 오피스(Idle office)**:
모든 에이전트가 쉬는 중인 오피스. 작업중이거나 질문 대기인 에이전트가 하나라도 있으면 노는 중 오피스가 아니다.
_Avoid_: 빈 오피스
