## 증상

- preview `6+sub5` 410px: plugin(member 0, 서브에이전트 5개)의 '+3' 배지가 plugin 오른쪽 세로 칸 맨 위, 바로 위 manager 쪽 임시 직원 명판 줄("waiter…", "sleepe…")의 오른쪽 끝에 같은 높이로 붙는다. 그래서 '+3'이 orchestrator 임시 직원 줄의 세 번째 칸, 즉 "orchestrator의 서브에이전트 3개 더"로 읽힌다.
- 480px에서는 '+3'이 "sleeper…" 명판 바로 아래, plugin 칸 위에 있어 덜 헷갈린다. 그래도 manager 줄과 가까워 어느 쪽 배지인지 바로 알기 어렵다.
- 가독성 자체는 괜찮다. 청록 점선 배지의 "+3"이 2배 확대 없이 읽힌다.
