# VQA-030 하단 책상이 방 아래쪽 벽(바닥 끝)에 너무 붙어 불안정해 보임 (사용자 피드백)

## 재현 조건

- 사용자 캡처: shots/recheck-8/v030-user-live-bottom-margin.png
