# VQA-005 빈 빈백이 항상 보이고 왼쪽 세로 줄에 겹쳐 쌓임 (기존 알려진 문제, 재확인)

- 심각도: 중간
- 추정 담당: scene (빈백 표시 조건, 슬롯 간격), art (빈백 크기와 화풍 일부)
- 상태: deferred (사용자 결정으로 보류)

## 증상
- 아무도 away가 아니어도(mixed, working) 왼쪽에 빈백 3개(N≤6) 또는 6개(N≥7)와 orchestrator 빈백이 항상 그려진다. N16 mixed에서는 화면 왼쪽 1/6이 빈 빈백 6개로 채워진다.
- 슬롯 간격(180px)이 빈백 높이(200px)보다 작아 빈백이 서로 겹쳐 쌓인다. 장식이 아니라 무더기로 보인다.
- 빈백 외곽선이 계단처럼 각져 있고 검은 테두리가 두꺼워서, 부드럽게 그린 책상·배경과 화풍이 어긋난다(확대 시).

## 재현 조건
- N=16 mixed, `setTime(15000)`, 480px
- N=6 mixed, `setTime(15000)`

## 왜 어색한가
쉬는 사람이 없는데 휴게 가구가 화면의 큰 비중을 차지한다. 겹쳐 쌓인 모습은 정리되지 않은 창고처럼 보인다.

## 기대 모습
빈 빈백은 숨기거나 1~2개만 장식으로 둔다. 사용 중인 빈백만 보이게 하거나, 간격을 넓혀 서로 겹치지 않게 한다.
