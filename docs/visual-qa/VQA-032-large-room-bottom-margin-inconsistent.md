# VQA-032 large 방에서 마지막 행 아래 빈 바닥이 인원 수에 따라 28~184px로 들쭉날쭉함

- 심각도: 중간
- 추정 담당: scene (`core/layout.ts`: large 방 최소 높이 1536 고정 + 행 수에 따른 높이)
- 상태: closed

## 증상
large 배경은 최소 높이 1536 logical px로 고정이고, 행이 4줄(N13~16)일 때만 늘어난다. 그래서 행이 적으면 아래쪽이 넓게 빈다.
- N7, N8(2행): 마지막 책상 아래 빈 바닥이 480px에서 184 CSS px, 410px에서 157 CSS px다. 방 높이의 1/3 정도가 빈 바닥이다.
- N10, N12(3행): 94px / 81px
- N13~16(4행): 33px / 28px
- 참고로 medium(N4~6)은 41px / 35px, small(N1~3)은 63px / 54px다.

## 재현 조건
- 멤버 수 7, 8, 10, 12, 13, 16, 480px와 410px, `setTime(20000)`

## 왜 어색한가
사용자가 요청한 것은 "안정적인 여백"인데, 인원 하나 차이(N6→N7)로 아래 여백이 41px에서 184px로 4배 넘게 뛴다. N7·N8은 사무실 아래쪽이 휑하게 비어 미완성처럼 보이고, 패널 스크롤만 길어진다. 반대로 N13~16은 여백이 가장 작다.

## 기대 모습
마지막 행과 아래쪽 벽 사이 여백이 인원 수와 관계없이 비슷하다(예: 480px에서 40~60 CSS px). large 방 높이를 행 수에 맞춰 줄이거나, 행 배치를 세로 가운데로 맞춘다.
