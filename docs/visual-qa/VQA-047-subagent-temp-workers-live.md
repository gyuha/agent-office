# VQA-047 실행 중인 서브에이전트 임시 직원 점검: 실제 앱 개수 비교와 퇴장 (forge 작업 #4 S4)

- 심각도: 중간
- 추정 담당: plugin (개수·이벤트 반영), scene (연출) — 미확인 항목 재점검 필요
- 상태: open (23차: 오피스 2명과 대시보드 실행 중 2개를 각각 봤지만 같은 프레임은 아님. reload 복원과 퇴장 미확인, 사용자 요청으로 실제 앱 조작 중단)
- 출처: forge task 4 `subagent-temp-workers` S4, C6

## 대상

- 기능: 부모 에이전트가 띄운 running provider 서브에이전트를 부모 오피스에 임시 직원으로 그린다(청록 점선 명판, 부모 책상 옆 축소 보조 책상, member는 오른쪽·manager는 왼쪽, 부모당 2칸, 넘치면 '+N'). 등장 0.4초 페이드인, 퇴장 0.6초 페이드아웃.
- 코드: `client/scene/core/workers.ts`, `client/scene/core/draw.ts`, `server/office.ts`, `shared/state/machine.ts`

## 방법

- `paseo plugin reload agent-office` 뒤 실제 Paseo 데스크톱 창을 agent-desktop 스크린샷(DPR2)으로 봤다.
- 테스트 에이전트(Haiku 5.5, auto)를 agent-office 워크스페이스에 만들어 Agent 도구로 서브에이전트 2개를 병렬로 띄우게 했다.
  - run1(vqa21-subagent-probe): 서브에이전트에 `sleep 100`을 시켰다. 하네스가 포그라운드 sleep을 막아, sleeper 1은 곧바로, sleeper 2는 백그라운드로 돌린 뒤 넘겨주며 끝났다.
  - run2: probe가 "sleep 차단 우회"라며 거절했다(서브에이전트 0개).
  - run3(vqa21-subagent-probe2): 첫 요청은 Monitor를 걸고 바로 끝났다. 두 번째 요청에서 waiter 3·4가 `/tmp/vqa21-release` 파일이 생길 때까지 포그라운드 until 루프로 기다렸고, 파일을 만들자 끝났다.
  - 두 테스트 에이전트는 아카이브했고 /tmp 파일도 지웠다. 다른 프로젝트 에이전트에는 손대지 않았다.
- preview: `client/scene/preview.html`의 `3+sub`, `6+sub`, `6+sub5`, `10+sub`, `solo+sub` × 480/410px, working, setTime 20000ms, 헤드리스 Chromium DPR2.

## 점검 중 생긴 일 (중요)

- 사용자가 같은 시각 앱을 쓰고 있었다. 화면이 여러 번 'office' 워크스페이스로 바뀌었다(푸시 완료 토스트 포함).
- 제가 이름으로 찾은 버튼이 의도한 탭이 아니었던 경우가 있었다. 'Greeting' 이름으로 사이드바 행을 누르려다 '에이전트 팀' 화면의 카드를 눌렀다. '대시보드' 이름으로 대시보드 탭을 누르려다 '전체 에이전트' 탭과, office 팀의 '제안 검토' 화면을 열었다(이름에 '대시보드'가 들어간 다른 버튼으로 추정). 누른 것은 이름에 'Greeting', '대시보드', 'Agent Office'가 들어간 버튼뿐이고, 삭제·재연결·저장 버튼은 누르지 않았다. 이 일 뒤로는 실제 앱 클릭을 모두 멈췄다.
- 그래서 대시보드와 오피스를 같은 프레임에 담는 비교, reload 복원 확인, run3 퇴장 확인은 오피스가 화면에 없는 상태에서 진행돼 보지 못했다.

## 24차 preview 결과 (2026-11-12, 디자인 변경 뒤, 실제 앱 미조작)

- 바뀐 디자인: 임시 직원이 정규 직원과 같은 pod 책상·의자·크기로, 방 책상 수 N에 들어간다. 표식은 청록 점선 명판이다.
- 6종(3+sub, 6+sub, 6+sub5, 10+sub, solo+sub, 16+sub) × 480/410px, working, setTime 20000:
  - 화풍·축척: 정규 직원과 같다. 같은 책상·의자·캐릭터 크기이고, 타이핑 자세도 같다.
  - 표식: 청록 명판 때문에 베이지 명판인 정규 직원과 바로 구분된다.
  - 명판 이름: 형제끼리 앞 단어를 빼고 구분된다("sleeper 1/2", "waiter 3/4"). 형제가 1명이면 원래 이름("vqa waiter…")을 쓴다.
  - 겹침·z-order·발 위치: 이상 없다.
  - +N: 16+sub에서 정규 16명으로 방이 차, 마지막 책상(ops) 오른쪽에 청록 '+5'가 붙는다. 480/410px 모두 읽히고 겹침이 없다.
- 클릭: 임시 직원 5명을 눌러도 선택이 바뀌지 않는다. 정규 직원 4명은 정상 선택된다.
- 관찰(문제로 열지 않음): 임시 직원은 정규 직원 뒤에 놓여 부모 책상과 떨어진다(예: orchestrator의 서브에이전트가 member 줄 끝에 앉음). 명판에 부모 표시가 없어 누구의 서브에이전트인지는 화면으로 알 수 없다. 지정된 디자인대로라 결함으로 보지 않았다. 부모를 알아볼 필요가 있으면 사용자가 정할 사항이다.
