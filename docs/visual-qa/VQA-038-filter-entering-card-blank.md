# VQA-038 필터 결과에 새로 들어오는 오피스 카드가 약 70~85ms 동안 빈 카드로 보임

- 심각도: 중간
- 추정 담당: scene (`mount-scene.ts` 카드 생성 직후 첫 그리기 시점)
- 상태: closed
- qa 회귀 테스트 필요

## 증상
필터가 걸린 상태에서 스냅샷이 바뀌어 오피스가 조건에 새로 들어오면 카드 DOM이 먼저 생긴다. 그런데 캔버스 저장소가 0×0인 채로 다음 12fps 틱까지 기다린다. 그동안 상단바(PROJECT/AGENT)만 있고 방 영역은 배경색으로 비어 보인다. VQA-036(스크롤로 들어오는 카드의 빈 상태)과 같은 종류인데, 이번에는 필터 판정 변화가 원인이다. 상태 변화마다 반복되므로 실제 사용 중 자주 보일 수 있다.

## 재현 조건
- preview `#filters`, 라이브 루프, `setFilter('working')`(또는 'idle') 뒤 `setSnapshot`으로 오피스 하나를 조건에 맞게 바꾼다.
- 측정(rAF 단위로 "화면에 보이는데 캔버스 폭 0"인 카드 확인, 폭별 3회 × 2필터):

| 폭 | 빈 카드가 처음 보인 시각 → 마지막 시각 (ms) |
|---|---|
| 480 | 84→163, 95→177, 73→153, 16→100, 71→151, 99→165 |
| 1200 | 76→157, 94→178, 67→147, 16→100, 80→151, 19→102 |
| 1600 | 81→161, 7→91, 79→150, 66→142, 81→151, 70→154 |

빈 상태는 매번 약 70~85ms(12fps 한 틱) 이어진다. 화면 캡처는 지연이 커서 이 순간을 잡지 못했다. 근거는 rAF 측정이다(VQA-036 캡처 `shots/recheck-10/v036-1200-scroll240-blank-card.png`와 같은 모습).

## 왜 어색한가
상태가 바뀔 때마다 카드가 "빈 틀 → 방"으로 깜빡인다.

## 기대 모습
카드를 넣는 같은 프레임에 첫 그림을 그리거나, 그려진 뒤에 카드를 보이게 한다.

## 재확인 결과 (2026-11-08, 13차 재확인)

- 같은 조건으로 18회 다시 쟀다(480/1200/1600px × Working·Idle × 3회, 라이브 루프, rAF마다 확인). 이번에는 검사를 두 가지로 했다. 하나는 화면에 보이는데 캔버스 폭이 0인 카드, 다른 하나는 캔버스 크기는 있지만 방 중앙 아래 픽셀이 아직 비어 있는(알파 0) 카드다. 두 검사 모두 18회 전부 0프레임이었다(지난번에는 매번 약 70~85ms).
- 회귀 확인: 스크롤로 들어오는 카드(VQA-036)도 1200·1600px에서 빈 상태 0회였다.
