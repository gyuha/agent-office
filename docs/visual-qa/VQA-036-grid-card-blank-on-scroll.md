# VQA-036 스크롤로 화면에 들어오는 카드가 잠깐 빈 상태(헤더만 있고 방이 비어 있음)로 보임

- 심각도: 중간
- 추정 담당: scene (`mount-room.ts`·`scheduler.ts` IntersectionObserver 해제/재생성 시점)
- 상태: closed
- qa 회귀 테스트 필요

## 증상
화면 밖 카드는 IntersectionObserver로 캔버스 저장소를 0×0으로 해제한다. 스크롤해서 카드가 화면에 들어오면 다음 그리기까지 캔버스가 0×0이라, DOM 헤더(PROJECT/WORKSPACE/AGENT) 아래 방 영역이 배경색으로 비어 보인다. 그 뒤 방이 갑자기 나타난다.
- 측정(DPR2, 120px 단위 스크롤, rAF 단위 폴링): 빈 상태가 16~87ms(1~11프레임) 이어졌다.
  - 1200×600: 4회 (25, 16, 87, 80ms)
  - 1600×700: 1회 (29ms)
  - 2000×800: 스크롤 거리 50px라 해당 없음
- 12fps 일정에 맞춰 그려서, 최악의 경우 거의 한 틱(83ms) 동안 빈 카드가 보인다.

## 왜 어색한가
스크롤할 때마다 카드가 비었다가 채워져 깜빡이는 느낌이 든다. 특히 천천히 스크롤하면 반복적으로 보인다.

## 기대 모습
화면에 들어오기 전에 미리 그린다. 예: IntersectionObserver에 `rootMargin`(위아래 한 화면 정도)을 줘 곧 보일 카드는 해제하지 않거나 미리 복원한다. 또는 해제할 때 마지막 프레임을 정적 이미지로 남겨 빈 영역이 보이지 않게 한다.

## 재확인 결과 (2026-11-07, 11차 재확인)

- DPR2 라이브 루프에서 1200×600, 1600×700, 2000×800 창을 60~120px 단위로 끝까지 스크롤하며 rAF마다 확인했다. 화면에 보이는 카드의 캔버스가 비어 있는 순간이 0회였다(지난번 1200px 4회, 1600px 1회). 카드별 스크린샷 20장(872px, 2000px)도 모두 방이 그려져 있었다.
